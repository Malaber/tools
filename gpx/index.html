    What does “combine” mean?

    A GPX activity is normally a track containing one or more track segments. This tool can place every source segment into one new track, preserving the original points and extensions, or concatenate all points into one segment.

    For separate real-world rides, keeping segments separate is usually safer because a continuous segment may imply movement between the end of one ride and the start of the next.
